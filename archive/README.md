# Preserved historical materials

This folder preserves materials that are not active runtime entry points. Archiving does not mean deleting a team member's work.

| Folder | Why it is here | Current use |
| --- | --- | --- |
| gesture-classification | Independent classifier experiment, unused by competition 3.2 | Historical experiment; not required for robot control |
| original-guides | Original README and collaboration document before reorganization | Current instructions are in the root README and docs |
| standalone-wheel-overlay | Original separately distributed steering-wheel display and instructions | The active wheel is `jackal-site/wheel-overlay.js` |

The steering wheel is still used. Its archived copy is a display component, not the robot controller. Historical controller programs, including the unchanged safety donor, are kept separately in `controllers/archive/`.
